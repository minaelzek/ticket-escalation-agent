# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

Please do not open a public GitHub issue for a security problem.

Use [private vulnerability reporting](https://github.com/minaelzek/ticket-escalation-agent/security/advisories/new), or email [minaaelzek@gmail.com](mailto:minaaelzek@gmail.com). Include the version and a sample ticket. You should get a reply within 7 days.

## Scope

This agent quotes a local markdown corpus. It has no network client and no credentials. Do not add a live customer mailbox or a production ticket system to this demo without an auth design and a review.

An answer is only as trustworthy as the file it cites. Treat low-confidence tickets as escalations, which is what the threshold is for.
